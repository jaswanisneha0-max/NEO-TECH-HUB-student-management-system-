# Student Management System

## 📌 Project Description
This is a PHP & MySQL based Student Management System developed as a college project.

## 🚀 Features
- Student Registration
- Login System
- Add / Edit / Delete Students
- Database Connectivity
- Admin Panel

## 🛠 Tech Stack
- PHP
- MySQL
- HTML
- CSS
- JavaScript
- XAMPP

## ⚙️ How to Run This Project

1. Download the project
2. Copy folder into htdocs
3. Import the database.sql file into phpMyAdmin
4. Start Apache & MySQL in XAMPP
5. Open http://localhost/project-folder-name

Database file included as: database.sql
